# Free-Chess.com-game-analyzer-
so this thing is a python code which when you run it you input your chess.com username and the click fetch games after that you select the game you want to analyze 
# IMPORTANT
First of all you need to download stock fish (the version or where you download dont matter but i recommend downloading it from https://github.com/official-stockfish/Stockfish/releases)
And it will load the stockfish without any problem and if any thing happend that it didnt managed to open stock fish just change the line 21 so it shows the place stockfish is and it needs libraries like python-chess and pillow (pip install requests python-chess pillow) and if you want to it shows the neo theme chess.com pieces you should download them and put em in the same folder as stockfish is
